Appsmith is configured entirely through environment variables. In a Docker Compose deployment, set them in the `environment:` block of `docker-compose.yml`. In Kubernetes, set them as Helm values or a Kubernetes `Secret`/`ConfigMap`. Changes take effect after the container restarts.

## Setting variables in Docker Compose

```yaml
version: "3"

services:
  appsmith:
    image: index.docker.io/appsmith/appsmith-ce:release
    container_name: appsmith
    ports:
      - "80:80"
      - "443:443"
    environment:
      APPSMITH_ENCRYPTION_PASSWORD: "my-strong-encryption-password"
      APPSMITH_ENCRYPTION_SALT: "my-random-salt-value"
      APPSMITH_MAIL_ENABLED: "true"
      APPSMITH_MAIL_HOST: "smtp.example.com"
      APPSMITH_MAIL_PORT: "587"
      APPSMITH_MAIL_USERNAME: "noreply@example.com"
      APPSMITH_MAIL_PASSWORD: "smtp-password"
      APPSMITH_MAIL_SMTP_AUTH: "true"
      APPSMITH_MAIL_SMTP_TLS_ENABLED: "true"
    volumes:
      - ./stacks:/appsmith-stacks
    restart: unless-stopped
```js

Apply changes by restarting the container:

```bash
docker compose down && docker compose up -d
```

## Variable reference

### Encryption

<Warning>
Set `APPSMITH_ENCRYPTION_PASSWORD` and `APPSMITH_ENCRYPTION_SALT` before the first run. These keys encrypt all datasource credentials stored in the database. **If you change them after data has been written, all existing encrypted credentials become unreadable.** Use long, random strings generated by a password manager or `openssl rand -base64 32`.
</Warning>

| Variable | Required | Description |
|---|---|---|
| `APPSMITH_ENCRYPTION_PASSWORD` | Yes | Master password used to derive the encryption key for stored credentials |
| `APPSMITH_ENCRYPTION_SALT` | Yes | Random salt combined with the password during key derivation |

**Example:**

```yaml
APPSMITH_ENCRYPTION_PASSWORD: "Xk9#mL2$vQp7nRz1"
APPSMITH_ENCRYPTION_SALT: "sJ4@wD8!yHc3bFt6"
```js

### Database

By default, Appsmith runs an embedded MongoDB instance. To use an external MongoDB cluster, set the URI variable.

| Variable | Default | Description |
|---|---|---|
| `APPSMITH_MONGODB_URI` | embedded | MongoDB connection string, e.g. `mongodb+srv://user:pass@cluster.example.com/appsmith` |
| `APPSMITH_REDIS_URL` | embedded | Redis connection URL, e.g. `redis://user:pass@redis.example.com:6379` |

**Example (external MongoDB Atlas cluster):**

```yaml
APPSMITH_MONGODB_URI: "mongodb+srv://appsmith:password@cluster0.example.mongodb.net/appsmith?retryWrites=true&w=majority"
```

### Email

Appsmith sends email for signup confirmation, password reset, and workspace invitations. Configure an SMTP server to enable these features.

| Variable | Description |
|---|---|
| `APPSMITH_MAIL_ENABLED` | Set to `true` to enable outbound email |
| `APPSMITH_MAIL_HOST` | SMTP server hostname, e.g. `smtp.sendgrid.net` |
| `APPSMITH_MAIL_PORT` | SMTP port, typically `587` (STARTTLS) or `465` (SSL) |
| `APPSMITH_MAIL_USERNAME` | SMTP authentication username |
| `APPSMITH_MAIL_PASSWORD` | SMTP authentication password |
| `APPSMITH_MAIL_SMTP_AUTH` | Set to `true` if the SMTP server requires authentication |
| `APPSMITH_MAIL_SMTP_TLS_ENABLED` | Set to `true` to enable STARTTLS |

**Example (SendGrid):**

```yaml
APPSMITH_MAIL_ENABLED: "true"
APPSMITH_MAIL_HOST: "smtp.sendgrid.net"
APPSMITH_MAIL_PORT: "587"
APPSMITH_MAIL_USERNAME: "apikey"
APPSMITH_MAIL_PASSWORD: "SG.xxxxxxxxxxxxxxxxxxxx"
APPSMITH_MAIL_SMTP_AUTH: "true"
APPSMITH_MAIL_SMTP_TLS_ENABLED: "true"
```js

### Authentication & SSO

| Variable | Description |
|---|---|
| `APPSMITH_OAUTH2_GOOGLE_CLIENT_ID` | Google OAuth2 client ID for Google login |
| `APPSMITH_OAUTH2_GOOGLE_CLIENT_SECRET` | Google OAuth2 client secret |
| `APPSMITH_OAUTH2_GITHUB_CLIENT_ID` | GitHub OAuth2 client ID for GitHub login |
| `APPSMITH_OAUTH2_GITHUB_CLIENT_SECRET` | GitHub OAuth2 client secret |
| `APPSMITH_FORM_LOGIN_DISABLED` | Set to `true` to disable email/password login |
| `APPSMITH_SIGNUP_DISABLED` | Set to `true` to prevent new user self-registration |

For SAML and OIDC SSO configuration, see [SSO setup guide](/guides/sso-setup).

**Example (GitHub login):**

```yaml
APPSMITH_OAUTH2_GITHUB_CLIENT_ID: "your-github-client-id"
APPSMITH_OAUTH2_GITHUB_CLIENT_SECRET: "your-github-client-secret"
```

### Application settings

| Variable | Default | Description |
|---|---|---|
| `APPSMITH_CLIENT_LOG_LEVEL` | `error` | Browser console log level: `debug` or `error` |
| `APPSMITH_DISABLE_TELEMETRY` | `false` | Set to `true` to opt out of anonymous usage analytics (self-hosted only) |
| `APPSMITH_DISABLE_INTERCOM` | `false` | Set to `true` to disable the Intercom support widget |
| `APPSMITH_RECAPTCHA_SITE_KEY` | — | Google reCAPTCHA v3 site key |
| `APPSMITH_RECAPTCHA_SECRET_KEY` | — | Google reCAPTCHA v3 secret key |
| `APPSMITH_RECAPTCHA_ENABLED` | `false` | Set to `true` to enable reCAPTCHA on the login page |
| `APPSMITH_SENTRY_DSN` | — | Sentry DSN for server-side error tracking |

## Kubernetes configuration

In a Helm-based deployment, pass environment variables as Helm values or reference them from a Kubernetes Secret using the `externalSecrets` section in `values.yaml`:

```yaml
externalSecrets:
  enabled: true
  refreshInterval: 1m
  remoteNameSecret: "appsmith-secrets"
```js

Or set values directly during install:

```bash
helm install appsmith appsmith/appsmith \
  --namespace appsmith \
  --set appsmith.encryptionPassword="my-strong-password" \
  --set appsmith.encryptionSalt="my-random-salt"
```
